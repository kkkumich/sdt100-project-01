Что сказать своими словами

while проверяет условие до выполнения, do-while — после, поэтому выполняется хотя бы один раз. for удобен для известного количества повторений. В развороте строк индекс идёт от length()-1 до 0. Вложенные циклы выполняют внутренний цикл для каждой итерации внешнего.

Вопросы преподавателя

Почему последний индекс length()-1?
Индексация начинается с нуля.

Что будет без изменения счётчика?
Условие может никогда не стать ложным, получится бесконечный цикл.

Почему в обратном отсчёте нет 6?
Именно такая последовательность указана в условии. Использован i-- и явный пропуск 6; если это опечатка преподавателя, условие if(i!=6) можно убрать.

Разворот через charAt отвечает учебному условию; для сложных Unicode-символов, состоящих из нескольких кодовых единиц, он не является универсальным текстовым алгоритмом.

        for(int i=0;i<length;i++) a[i]=Input.integer("Element "+i+": ",Integer.MIN_VALUE,Integer.MAX_VALUE);

        int[] a=new int[length]; for(int i=0;i<length;i++) a[i]=random.nextInt(100); return a;
    }
    public static void printArray(int[] a) { System.out.println(Arrays.toString(a)); }
    public static void sort(int[] a) {
        for(int end=a.length-1;end>0;end--) {
            boolean swapped=false;
            // After each pass, the maximum in the unsorted prefix reaches end.
            for(int j=0;j<end;j++) if(a[j]>a[j+1]) {
                int temp=a[j]; a[j]=a[j+1]; a[j+1]=temp; swapped=true;
            }
            if(!swapped) break;
        }
    }
    public static void main(String[] args) {
        do {
            int n=Input.integer("Number of elements (0-1000): ",0,1000);
            String mode=Input.text("G: generate; anything else: input: ");
